# 配置与订阅

配置文件是 Swihomo 运行的 mihomo 配置。本地 YAML 文件与在线订阅并列显示在「配置文件」页，可以随时切换。配置文件保存在应用的私有存储中，因此应从应用内管理，而不是在文件系统中操作。

## 配置文件页面

每个配置文件是一张卡片，显示配置的来源：

- **本地**表示导入的 YAML 文件，详情显示「已导入的配置」。
- **在线**表示订阅，详情显示订阅主机。
- 当前活动卡片标记为「活动」，并在连接时提供所用配置。
- 卡片显示「更新于 …」；日期未知时显示「更新于 —」。在线卡片在订阅服务器返回相应信息时显示「订阅」用量与「到期」；若在偏好中将「显示订阅信息」设为「隐藏」，用量行会被隐藏。

## 导入本地配置

1. 打开「配置文件」。
2. 打开「更多」菜单并选择「导入」。
3. 选择一个 UTF-8 编码的 YAML 配置文件。

一次只能导入一个文件，配置文件名称取自去掉扩展名的文件名。空文件会被拒绝。本地配置没有重命名操作，也没有「刷新」按钮；需要修改时，使用卡片菜单中的「编辑内容」。

## 添加在线订阅

1. 打开「配置文件」，点「网络源」。
2. 填写订阅详情：

   - **订阅 URL**：必填，必须是带主机名的 HTTP 或 HTTPS 地址。Swihomo 会在输入时校验；地址无效时提示「请输入有效的 HTTP 或 HTTPS URL」。
   - **配置文件名称**：可选。留空时使用订阅主机；此名称仅用于在 Swihomo 中标识配置文件。
   - **自定义 User-Agent**：可选。用于初次下载及之后的每次刷新，默认值为 `ClashMeta/<mihomo-version>`，版本号来自内置的 mihomo 核心。留空即使用默认值。

3. 点「添加配置文件」。URL 有效前，该按钮不可用。

下载超时为 30 秒，HTTP 错误会作为失败报告。Swihomo 支持 mihomo YAML 配置、JSON 订阅列表、常见分享链接列表与 Base64 编码的订阅。若 JSON 内容为节点数组，Swihomo 会将其包装为包含 `Proxy` 组与 `MATCH` 规则的配置文件。

## 通过二维码添加（仅 iOS）

在「配置文件」页点「更多」→「扫描二维码」，将相机对准包含 HTTP 或 HTTPS 订阅 URL 的二维码。有效的二维码会打开「添加在线配置文件」并预填 URL；在确认并点「添加配置文件」之前，不会导入任何内容。如果二维码内容不是可用的 URL，扫描页面会提示「此二维码不是订阅 URL」。相机不可用时，可按提示前往系统设置检查权限，或重试。

## 连接与切换

点卡片上的「连接」启动隧道。该配置文件为活动且已连接时，按钮显示「已连接」。

隧道运行时点另一张卡片的「连接」会自动切换：Swihomo 先断开，再用新选择的配置文件重新连接。首次连接还会显示系统 VPN 配置权限提示。[设置](/zh/settings)说明了哪些更改需要重新连接。

## 保持订阅更新

在线配置文件有两条编辑路径，作用不同：

- **刷新**：使用已保存的 URL 与 User-Agent 重新下载订阅，替换已保存的内容，并更新「更新于」日期与订阅用量。刷新是手动操作，没有计划任务或自动刷新。
- **编辑配置文件**：修改订阅 URL、「配置文件名称」或「自定义 User-Agent」。这是重命名在线配置文件的唯一方式；在刷新前不会下载任何内容。

所有配置文件都可以使用「编辑内容」，它会打开 YAML 编辑器，保存后更新「更新于」日期。对在线配置而言，此修改只作用于本机：订阅 URL 不变，下一次「刷新」会覆盖保存的内容。

::: warning 注意
需要长期保留的更改，请使用配置文件覆盖，而不是直接编辑订阅内容。
:::

## 配置文件覆盖

打开卡片的「更多」菜单并选择「覆盖设置...」，可以自定义单个配置文件。页面标题为「配置文件自定义覆盖」，说明为「应用于全局自定义 YAML 之后, 标准覆盖之前」。

- **启用全局覆盖**决定此配置文件是否同时应用全局[覆盖设置](/zh/settings#overrides)页中的自定义 YAML，默认开启。
- YAML 编辑器接受与全局编辑器相同的 Mihomo Party 语法。

配置文件连接时，Swihomo 按以下顺序合并：

1. 配置文件自身的配置
2. 全局自定义 YAML（若「启用全局覆盖」开启）
3. 此配置文件的自定义 YAML
4. 由全局基本设置生成的标准覆盖，这些值始终优先
5. 可选的地理数据到规则集改写

覆盖 YAML 遵循 Mihomo Party 语法：

- `key!`：替换现有对象
- `+key` 或 `key+`：在数组前插入或向后追加数组项
- `<key>`：转义以 `+` 开头或结尾的字面量键

更多示例见 [Mihomo Party 覆盖参考](https://clashparty.org/docs/guide/override/yaml)。

已保存的覆盖更改会在该配置文件下次连接时生效。

## 删除配置文件

打开卡片的「更多」菜单并选择「删除配置文件」。确认对话框说明配置文件及其存储的配置会被移除，且操作无法撤销。若删除的是当前活动配置文件，活动选择会被清除；再次连接前请先选择其他配置文件。
