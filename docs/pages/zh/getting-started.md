# 快速开始

Swihomo 在系统 VPN 隧道中运行 mihomo 核心，因此可以使用自己的配置或订阅，无需额外的辅助应用。本指南从安装开始，一直到确认流量正常。更完整的操作说明见[配置与订阅](/zh/profiles)与[设置](/zh/settings)。

## 1. 安装

Swihomo 需要 iOS 17 或更高版本，或 macOS 14 或更高版本。目前可通过 TestFlight 安装：

[加入 TestFlight](https://testflight.apple.com/join/ayecJQT4)

App Store 版本尚未推出。接受 TestFlight 邀请，安装构建版本，然后打开 Swihomo。

## 2. 添加配置文件

在「主页」打开「配置文件」，任选一种方式添加：

- **本地 YAML**：点「更多」（…）→「导入」，然后选取一个 `.yaml` 或 `.yml` 文件。配置文件名称取自文件名。
- **在线订阅**：点「网络源」，填写 HTTP 或 HTTPS 订阅 URL。「配置文件名称」可以留空，此时使用订阅主机作为名称。
- **二维码（仅 iOS）**：点「更多」→「扫描二维码」，然后扫描包含订阅 URL 的二维码。扫描后会打开已预填 URL 的「添加在线配置文件」页面，确认后才会下载。

## 3. 连接

在配置文件卡片上点「连接」，也可以使用「主页」上的连接开关。首次连接时，系统会显示标准的 VPN 配置提示，请按提示允许。

已连接时选择另一个配置文件并点「连接」，Swihomo 会自动断开当前连接并切换到新配置文件，无需手动重新连接。

## 4. 确认连接状态

返回「主页」，状态卡应显示「已连接」，下方为当前配置文件的名称。

以下页面可进一步确认流量确实在传输：

- 「连接」列出实时连接、匹配的规则与速度，仅在已连接时显示内容。
- 「日志」记录应用与 mihomo 核心事件，核心事件在已连接时到达。

如果表现与预期不符，见[状态与故障排查](/zh/troubleshooting)。
